Fast Venue Rank

Journal and conference rankings next to Google Scholar results. All rankings come from bundled tables; the network is only used to identify a paper's venue.

Rankings

Custom ranking

Import your own list (institutional, field-specific…). Matched by ISSN, exact journal name, or — for one-word names such as CVPR — conference acronym. CSV needs a header with ISSN and/or Name (or Journal / Title), Rank (or Rating) and optionally Description. JSON may be {"1234-5678": "A*", "Journal name": "B"}, an array of {issn, name, rank, description}, or {"key": {name, rank, description}}.

Catalog updates

The ranking tables are rebuilt monthly and published on GitHub. The extension checks once a week and downloads only changed tables (checksummed and validated; the bundled tables stay as fallback).

To build the tables yourself: uv run scripts/build_data.py, then reload the extension.
